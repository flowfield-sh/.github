# A workspace for you and your coding agents.

Plan, build, and refine software together. Flowfield keeps the work moving and the context intact.

We're building a company around a simple conviction: as agents can implement more,
human attention becomes the constraint. Developers should be able to shape a product
through conversation, testing and revision without spending their time carrying context
between sessions or keeping parallel work aligned with an evolving roadmap.

**[Flowfield](https://github.com/flowfield-sh/flowfield-core)** is our open-source local
workspace. Plan with a coordinating agent, run independent tasks in parallel, and bring
progress, questions, feedback and results into a shared task feed. The work persists
beyond individual agent sessions. Flowfield currently integrates with Codex.

**Flowfield Cloud** is in development: a future hosted workspace for shared collaboration.
[Get updates](https://buttondown.com/flowfield).
